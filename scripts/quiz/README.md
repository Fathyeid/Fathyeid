# بنك أسئلة «الموسوعة الإسلامية | اختبر علمك»

القسم يعمل دون إنترنت بالكامل: الأسئلة ملفات JSON في `data/quiz/` تُشحن مع التطبيق،
ويُحمَّل ملف التصنيف عند فتحه فقط. تقدّم المستخدم يُحفظ على جهازه (localStorage، مفاتيح `noor:qz:*`).

## البناء
```bash
bash scripts/quiz/build.sh
```
يقرأ `scripts/quiz/src/*.json` ويكتب `data/quiz/<تصنيف>.json` و`data/quiz/index.json`.
ويفشل البناء إذا خالف أي سؤال قواعد التحقق أدناه.

## إضافة سؤال
أضف عنصراً إلى ملف التصنيف المناسب في `src/` (أو ملفاً جديداً بالحقل `c` المناسب):

| الحقل | المعنى |
|---|---|
| `id` | معرّف ثابت فريد (لا يُغيَّر أبداً؛ عليه يُحفظ تقدّم المستخدم) |
| `c` | التصنيف: quran, tafsir, hadith, seerah, anbiya, sahaba, fiqh, salah, siyam, aqeedah, akhlaq, adhkar, tarikh, general, muamalat |
| `t` | النوع: `mcq` اختيار، `tf` صح/خطأ (`o` = `["صح","خطأ"]`)، `cmp` أكمل، `who` من القائل، `mean` ما المقصود، `ord` رتّب (`a` مصفوفة الترتيب الصحيح) |
| `l` | المستوى: ١ مبتدئ، ٢ متوسط، ٣ متقدم، ٤ تحدي العلماء |
| `q`, `o`, `a` | نص السؤال، الاختيارات (٤)، رقم الإجابة الصحيحة (الأول عادةً؛ تُخلط وقت العرض) |
| `e`, `r` | الشرح، والمرجع (إلزاميان) |
| `d` | الأدلة: `{"q":[سورة,آية]}` أو `{"q":[سورة,آية],"w":[من,إلى]}` أو `{"q":[سورة,من,إلى]}`، و`{"h":"لفظ الحديث","src":"البخاري (رقم)","g":"الدرجة"}` (و`hm` للفظ مسلم إن اختلف) |
| `w` | (اختياري) سبب خطأ كل اختيار، بنفس ترتيب `o` |
| `x` | (اختياري) تنبيه بوجود خلاف فقهي معتبر |

## قواعد الجودة التي يفرضها البناء
- **لا يُكتب نص قرآني يدوياً**: يُكتب المرجع `⟦2:255⟧` (آية) أو `⟦2:255:1-6⟧` (كلمات من آية) أو `⟦2:285-286⟧` (آيات)، فيُدرج النص من المصحف العثماني (quran-json، عن موسوعة القرآن الكريم quranenc.com). ويرفض البناء أي اختيار يطابق نصاً قرآنياً مكتوباً بالإملاء الحديث.
- **كل حديث منسوب إلى البخاري أو مسلم** يجب أن يوجد لفظه في نص الصحيح (sahih-al-bukhari، sahih-muslim). أرقام الأحاديث بالترقيم المشهور (فتح الباري / محمد فؤاد عبد الباقي) وتُراجع يدوياً.
- **الحديث من غير الصحيحين** يجب أن تُذكر درجته في `g`.
- أسئلة «أكمل الآية» المولّدة: بداية الآية فريدة في المصحف كله، ولا يصلح أي اختيار خاطئ تكملةً لها في أي موضع.
- المسائل الخلافية تُصاغ بـ«عند الجمهور» ويوضَّح الخلاف في `x`.

يُنصح بمراجعة كل سؤال جديد من طالب علم قبل إضافته.
