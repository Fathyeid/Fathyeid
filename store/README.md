## إجابات النماذج في Play Console

**أمان البيانات (Data safety)**
- هل يجمع التطبيق أو يشارك أي بيانات مستخدم؟ ← **لا**
  (الموقع يُستخدم على الجهاز فقط ولا يُرسل لأي خادم)
- هل البيانات مشفّرة أثناء النقل؟ ← **نعم** (كل الاتصالات HTTPS)

**الإعلانات** ← التطبيق **لا يحتوي** على إعلانات

**الوصول إلى التطبيق** ← كل الوظائف متاحة **بدون تسجيل دخول**

**تقييم المحتوى** ← الفئة: **مرجعي/تعليمي أو غير ذلك**، والإجابة بـ«لا» على أسئلة العنف والمحتوى الجنسي واللغة والمقامرة وغيرها

**الجمهور المستهدف** ← **١٨ سنة فأكثر** (أو ١٣+)؛ اختيار فئات الأطفال يُخضع التطبيق لسياسة العائلات ومتطلبات إضافية

**تطبيق إخباري** ← لا

**الأذونات الحساسة**: إذن «المنبّهات الدقيقة» (SCHEDULE_EXACT_ALARM) يُستخدم لتنبيه الأذان في موعده، ويطلب التطبيق موافقة المستخدم عليه.
