# أثر - رفيق المسلم 🌙

> **صدقة جارية على روح المرحوم عيد فتحي أبو طالب** — اللهم اغفر له وارحمه، وعافه واعف عنه، وأكرم نزله، ووسّع مدخله.

تطبيق إسلامي احترافي باللغة العربية، يعمل على الجوال والحاسوب كتطبيق ويب تقدّمي (PWA) قابل للتثبيت ويعمل دون اتصال.

## المميزات

- **🕌 مواقيت الصلاة**: حساب فلكي دقيق على الجهاز نفسه (بدون إنترنت) مع ٩ طرق حساب (الهيئة المصرية، أم القرى، رابطة العالم الإسلامي، ...) والمذهب الحنفي/الجمهور في العصر، وعدّ تنازلي للصلاة القادمة وتنبيه عند دخول الوقت.
- **📖 القرآن الكريم**: ١١٤ سورة بالرسم العثماني، بحث بالاسم أو الرقم، تلاوة صوتية آية بآية مع تظليل الآية الحالية، ٥ قرّاء، تكبير/تصغير الخط، وحفظ آخر موضع قراءة.
- **☀️ الأذكار**: أذكار الصباح والمساء وبعد الصلاة والنوم مع عدّاد لكل ذكر وشريط تقدّم يُحفظ يومياً.
- **📿 السبحة الإلكترونية**: أذكار جاهزة، أهداف (٣٣ / ١٠٠ / ١٠٠٠ / مفتوح)، اهتزاز، وإحصائيات يومية وإجمالية.
- **🧭 اتجاه القبلة**: زاوية القبلة والمسافة إلى مكة، مع بوصلة حية على الأجهزة الداعمة.
- **✨ أسماء الله الحسنى** التسعة والتسعون.
- **📅 التاريخ الهجري** (تقويم أم القرى) والميلادي، وآية وحديث لكل يوم.
- **📚 التفسير الميسر** لكل آية، و**وضع الحفظ** بتكرار الآية (٣ / ٥ / ١٠ مرات)، و**العلامات المرجعية**، و**مشاركة الآيات**.
- **🔍 البحث في آيات القرآن** كله بكلمة، و**القراءة بالأجزاء** الثلاثين.
- **📗 ختمة القرآن**: خطة ختمة (٧ / ١٥ / ٣٠ / ٦٠ يوماً) مع حساب الورد اليومي ومتابعة الأجزاء.
- **✅ متابعة الصلوات**: تسجيل الصلوات اليومية، سجل آخر ٧ أيام، الأيام المتتالية، وعدّاد قضاء الفوائت.
- **📅 التقويم الهجري**: شهر هجري كامل مع المناسبات القادمة (رمضان، العيدين، عرفة، عاشوراء، الأيام البيض) والعدّ التنازلي لها.
- **💰 حاسبة الزكاة**: نقود وذهب (٢٤ / ٢١ / ١٨) وفضة وديون، مع حساب النصاب تلقائياً.
- **🤲 أدعية قرآنية** و**أدعية للمتوفى**.
- **🎨 وضع فاتح وداكن** وتصميم عربي كامل من اليمين لليسار.

## التشغيل

لا يحتاج أي تثبيت أو بناء. شغّل خادماً محلياً بسيطاً في مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`. لنشره مجاناً يمكن تفعيل **GitHub Pages** على هذا المستودع.

## هيكل المشروع

```
index.html            الواجهة الرئيسية
css/style.css         التصميم (فاتح/داكن)
js/praytimes.js       خوارزمية حساب المواقيت والقبلة
js/data.js            الأذكار والأسماء الحسنى والمدن
js/app.js             منطق التطبيق والتنقل
sw.js                 العمل دون اتصال
manifest.webmanifest  إعدادات التثبيت كتطبيق
```

## مصادر البيانات

- نص القرآن الكريم: [AlQuran Cloud API](https://alquran.cloud/api) (الرسم العثماني).
- التلاوات الصوتية: [Islamic Network CDN](https://cdn.islamic.network).
- مواقيت الصلاة والقبلة: تُحسب محلياً بالمعادلات الفلكية.
